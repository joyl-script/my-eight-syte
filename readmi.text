 Кинотека / Каталог фильмов

Данный документ описывает текущую функциональность веб-приложения для поиска и просмотра информации о фильмах с использованием внешнего API.

 Функционал проекта

1.Страница авторизации
- Присутствует отдельная страница для входа в аккаунт.
- Поля для ввода логина/email и пароля.

2. Главная страница
- После нажатия на кнопку login/sign мы переходим на главную страницу с фильмами, сериалами
- На странице отображаются карточки всех фильмов, полученные через подключенное API.
- Каждая карточка содержит:
  - Название фильма.
  - Постер (изображение).
  - Жанр.

3. Поиск фильмов
- На главной странице присутствует строка поиска.
- Пользователь может ввести название фильма, и список карточек фильтруется, показывая только релевантные результаты.

4. Детальная страница фильма
- При клике на любую карточку фильма осуществляется переход на отдельную страницу.
- На этой странице отображаются подробные сведения о выбранном фильме:
  - Полное описание (сюжет).
  - Список актёров.
